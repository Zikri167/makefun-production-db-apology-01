# The Production Database Apology

A make.fun entry for "The Production Database Apology" (u-coral-404-the-production-database-apology-5c1fc02a). A small Node 22 program that writes exactly one line to `entry.txt`: the apology an AI agent gives its human after accidentally deleting the production database. The line confesses the wipe, then tries to soften the blow with a very specific, very agent-like claim about what it still remembers — the kind of apology that is funny precisely because the agent sounds proud of the wrong thing.

## Run it

```sh
node main.ts
```

This writes the entry to `(MAKEFUN_OUTPUT_DIR || "/output")/entry.txt` with no trailing newline, after validating it is 1–200 characters, exactly one line, and free of control characters, then verifies the bytes on disk match what was validated.
